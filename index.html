Herencia y Polimorfismo

La Programación Orientada a Objetos (POO) es un paradigma de programación que organiza el código mediante clases y objetos. Dentro de este paradigma existen conceptos fundamentales como la herencia y el polimorfismo.

1. Herencia

¿Qué es la Herencia?

La herencia es un mecanismo que permite que una clase obtenga atributos y métodos de otra clase.

Clase Padre: clase principal.

Clase Hija: clase que hereda características de la clase padre.

¿Para qué sirve?

  • Reutilizar código.
  • Evitar repetir instrucciones.
  • Organizar programas.
  • Facilitar mantenimiento.

Características de la Herencia

Característica Descripción
Reutilización Permite usar código ya creado.
Jerarquía Organiza clases en niveles.
Extensión Las clases hijas agregan nuevas funciones.

Ejemplo de Herencia

class Animal:

    def __init__(self, nombre):
        self.nombre = nombre

    def hacer_sonido(self):
        print("El animal hace un sonido")


class Perro(Animal):

    def ladrar(self):
        print("Guau Guau")


mi_perro = Perro("Max")

print(mi_perro.nombre)
mi_perro.hacer_sonido()
mi_perro.ladrar()

Resultado

Max
El animal hace un sonido
Guau Guau

2. Polimorfismo

¿Qué es el Polimorfismo?

El polimorfismo significa “muchas formas”. Permite que un mismo método tenga comportamientos diferentes según el objeto.

Ejemplo:

Un perro, un gato y una vaca pueden usar el método hacer_sonido(), pero cada uno responde diferente.

¿Para qué sirve?

  • Hace programas más flexibles.
  • Mejora la reutilización.
  • Reduce complejidad.
  • Permite usar métodos iguales.

Características del Polimorfismo

Característica Descripción
Flexibilidad El método cambia según el objeto.
Sobrescritura Permite modificar métodos heredados.
Adaptabilidad El código se adapta fácilmente.

Ejemplo de Polimorfismo

class Perro:

    def hacer_sonido(self):
        print("Guau Guau")


class Gato:

    def hacer_sonido(self):
        print("Miau")


class Vaca:

    def hacer_sonido(self):
        print("Muuu")


animales = [Perro(), Gato(), Vaca()]

for animal in animales:
    animal.hacer_sonido()

Resultado

Guau Guau
Miau
Muuu

3. Diferencias

Herencia Polimorfismo
Hereda características. Permite distintos comportamientos.
Usa clases padre e hija. Usa métodos iguales.
Reutiliza código. Hace el código flexible.

4. Conclusión

La herencia y el polimorfismo son pilares fundamentales de la Programación Orientada a Objetos.

Gracias a estos conceptos, los programas son más organizados, reutilizables y fáciles de mantener.
